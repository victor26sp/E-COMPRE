      Arquivar Movimentos Antigos

      Para melhorar a performance, arquive movimentos antigos. Isso calculará o saldo líquido dos movimentos até a data de corte, ajustará o estoque inicial dos produtos e removerá os movimentos antigos da lista principal, oferecendo um backup para download. Esta ação é irreversível.
